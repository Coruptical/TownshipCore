Economy system:
- GUI system for players, size adjustable list
of items that have buy/sell price
- The buy requires that the player has the money
- The sell requires that the player has the items in inventory
- Economy handled by vault
- Button to add a new item into the trade with preset buy/sell value

Backend for economy:
- GUI system stored in yaml file, list of objects
- Each object has a name (PK), and contains two attributes (buyPrice, sellPrice)
- This will auto update every 5 mins, while live updates stay in RAM
- In plugin RAM -> Hashmap<ItemName(STRING), MarketItem(Object)>
